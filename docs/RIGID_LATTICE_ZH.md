# 刚性晶格系综：不考虑 colloidal 散开，只算转动

本文接在 `MC_WORKFLOW_ZH.md` 之后。上一轮的结论是：在团簇系综中，27 颗粒超晶格会散开。本文回答两个问题：为什么会散开；在"超晶格已经存在"的前提下，立方体本体的转动、SL 整体的偏转以及总能量的最优构型是什么。

## 1. 为什么会散开：自由能 = 能量 − 温度 × 熵

| 状态 | 总能量 U | vdW | 偶极 |
|---|---|---|---|
| 紧凑晶格（磁矩已弛豫，晶格完整） | −644.7 kBT | −37.3 | −79.5 |
| 散开的团簇（v2 生产的平均值） | −570.6 kBT | −4.9 | −60.3 |

- **能量确实偏向晶格**：晶格比散开态低 74 kBT，但分到 26 个可动颗粒上，每个颗粒只有约 2.9 kBT。原因是 V9 晶格（a = 21 nm，α = 74.2°）中的接触主要是棱对棱，单个接触的 vdW 不到 1 kBT。偶极作用中，头尾相接的吸引与并排排列的排斥大部分相互抵消。Zeeman（约 14 kBT/颗粒）和各向异性（约 6.6 kBT/颗粒）虽然大，但都是单颗粒项，不起粘结作用。
- **熵偏向散开，而且大得多**：
  - 平移：在晶格中，颗粒被 1.8 nm 的 steric 墙卡住，每个方向只剩约 0.1 nm 的余量；散开后，可以在连通约束允许的约 10⁵ nm³ 体积内运动。每个颗粒得到约 ln(10⁵ / 10⁻²) ≈ 16 kBT。
  - 转动：在晶格中姿态只有几度的余量，自由时可以取任意取向。每个颗粒得到约 13 kBT。
  - 合计 26 × (16 + 13) ≈ 700 kBT，约为能量差的 10 倍。
- **单独一对也不结合**（`outputs/pair_binding/`）：接触概率随可用体积改变（30 nm 球内 24 %，36 nm 球内 14 %），接触时的平均 vdW 只有 −0.3 kBT。
- **推论**：vdW 即使再强 5 倍，也补不上这个熵差；要维持晶格，每个颗粒需要约 25–30 kBT 的结合能。实验中的 SL 是在溶剂挥发、毛细作用、配体交错等过程中形成，然后被动力学锁定的。这些作用都不在当前的哈密顿量里。

所以，"不考虑 colloidal 的情况"在物理上就是：**把 SL 当作已经形成、被锁定的结构，只问它内部的转动自由度如何分布**。这是一个条件问题：它回答"在 SL 存在的前提下会怎样"，不回答"SL 会不会形成"。

## 2. 刚性晶格系综的定义

- **位置**：固定在实验晶格上（3×3×3 菱方，a = 21 nm，α = 74.2°），整体只能刚性转动：r_k = r_0 + G · s_k，G ∈ SO(3)。
- **自由度**：SL 整体取向 G，27 个立方体姿态 Q_i ∈ SO(3)，27 个磁矩 m_i ∈ S²。
- **目标分布**：π(G, Q, m) ∝ exp(−U/kT) · 1[锐边核间距 ≥ D₀]。能量与之前完全相同（Zeeman、立方各向异性、偶极、steric、收敛 vdW）。
- **归一化**：状态空间 SO(3) × SO(3)²⁷ × (S²)²⁷ 是紧的，所以 π 自动可以归一化，不需要连通性约束。这正是上一轮团簇系综所缺少的性质。
- **观测量**：
  - SL 轴倾角：SL 三次轴 G·x̂ 与场的夹角；
  - 每个立方体相对晶格理想取向的转角 ω_i = ∠(Gᵀ Q_i Q_refᵀ)；
  - 本体 [111] 相对场的倾角；
  - 磁化，以及各能量项。

### move 与正确性

| move | 作用 | 为什么保持 π 不变 |
|---|---|---|
| 单立方体转动 | Q_i ← R Q_i，两尺度混合 1° / 4° | 相对 Haar 测度对称（与之前相同） |
| 共旋转（co-tilt） | G、全部 r 与全部 Q 一起转动 | 刚体转动保持测度；vdW 与 steric 不变，只有各向异性和偶极改变 |
| 共扭转 γ | 全部 Q 绕平均 [111] 轴转动 | 转轴在转动下不变，散度为 0（与之前相同） |
| 磁矩转动 | m_i ← R m_i | 与之前相同 |
| 晶格转动 | G 与全部 r 转动，本体不动 | 对称、保测度；生产中关闭，原因见下 |

- 新增的单元测试（`tests/test_lattice.py`）：
  - 两颗粒相距 40 nm、磁矩固定的"晶格"：晶格转动和共旋转采样得到的 E[cos²θ] 都与一维数值积分一致；
  - 紧凑晶格上的能量缓存与从头计算一致，位置严格等于参考晶格经 G 转动后的位置（误差 6.6e−15 nm）；
  - 退火在单磁矩问题上找到网格最小值（误差 < 1e−3 kBT）。
- 共旋转时沿用缓存的 vdW。求积在刚体转动下的不变性精确到舍入误差，实测 drift 约为 1e−9 kBT，远低于 1e−6 的门槛。
- 紧凑晶格中近接触对很多，所以使用略宽松的求积设置（q_near = 5，tol = 1e−4 kBT，数值检查窗口 8 倍）。在 4231 个允许的接触基准对上，最大误差为 2.9e−6 kBT，速度快 35 %。

### 调参（`outputs/pilot_tuning_lattice/`，MSJD 阶梯）

| move | 最优步长 | 接受率 | 说明 |
|---|---|---|---|
| 单立方体转动 | 4°（2–4° 是平台） | 0.12–0.23 | 立方体被笼子紧紧卡住 |
| 共旋转 | 24° | 0.22 | SL 整体偏转主要靠这一 move |
| 共扭转 γ | 4° | 0.36 | |
| 晶格转动（本体不动） | ≤ 0.125°（在阶梯边界） | 0.10 | MSJD 比共旋转小 10⁵ 倍 |

最后一行本身就是一个物理结论：晶格相对本体的取向被 steric 笼子锁死了，**SL 的偏转必须带着立方体一起转**。把晶格转动关掉不影响正确性，因为共旋转加上单立方体转动已经可以到达任意 (G, Q)。关掉它能省下约 15 % 的计算时间。

## 3. 采样与优化：两个不同的问题

- **298 K 采样**（`configs/lattice_production.json`）：步长固定，4 个初始 SL 倾角（0°、20°、40°、60°）× 4 个 seed，每条 2000 cycles，warm-up 事先定为 500。它给出热平均和分布，包括笼子里的熵。
- **模拟退火**（`configs/lattice_anneal.json`，"MCMC 优化"）：同样的 move 与接受规则，但 kT 按几何级数从 5 kT 降到 0.002 kT（1500 cycles），步长每 20 cycles 向 30 % 接受率调整一次，保留找到的最低能量构型。4 个初态 × 2 个 seed，共 8 次独立重启。

两者遵守的规则不同：
- 采样要求细致平衡、核固定不变、要做收敛诊断；
- 优化可以自适应调整步长，因为不求平均，只要"最好的状态"。
- 退火只有在对数降温 T_k ~ c / log k 下才保证找到全局最小，这太慢，没法用；几何降温只是启发式方法。所以判断是否找到全局最小的证据是：不同初态的独立重启给出相同的最低能量和结构；再对最优状态做局部检验（400 次极小的随机扰动，都不应降低能量）。
- 最小能量是 T = 0 的答案；298 K 下还有熵。所以退火结果要和 298 K 的分布对照，而不能用它来代替分布。

## 4. 结果

### 4.1 298 K 采样

第一轮运行（2000 cycles，warm-up 500）显示，立方体绕 [111] 的集体扭转需要约 1000 cycles 才能弛豫，比事先定的 warm-up 长。我没有事后改动 warm-up，而是把 16 条链从末态接着跑 1500 cycles，用新的 seed，并事先规定整段第一轮都算 warm-up。下面是续跑的结果（`outputs/lattice_production_cont/REPORT.md`）：

| 观测量 | 均值 ± MCSE | R-hat | 说明 |
|---|---|---|---|
| 总能量 | −660.6 ± 0.08 kBT | 1.005 | 比晶格初态低约 15 kBT |
| 磁化 m_x | 0.9612 ± 0.0001 | 1.007 | 散开团簇中为 0.931 |
| 偶极能 / 各向异性能 | −85.05 / −159.5 kBT | 1.00 / 1.01 | |
| **SL 轴倾角** | **4.81° ± 0.09°**（中位数 4.56°，90 % 区间 1.3–9.3°） | 1.025 | 四种初态（0°、20°、40°、60°）都回到同一个分布 |
| 本体 [111] 相对场的倾角 | 4.81° | 1.022 | 与 SL 轴一起摆动 |
| 立方体相对晶格的转角 | 16.5°（主要是绕 [111] 的扭转） | 2.0 | **还在缓慢弛豫** |
| 各立方体 [111] 与晶格轴的夹角 | 5.7° | 2.3 | **还在缓慢弛豫** |
| vdW | −48.1 kBT | 1.66 | 随扭转缓慢增强 |

- **SL 整体偏转**：每单位立体角的自由能 F(θ) = −kT ln[p(θ)/sin θ] 在 0–2° 最低，然后单调上升：3° 为 0.2 kBT，9° 为 2.6 kBT，15° 为 7.7 kBT。这是一个中心在 0° 的谐振子阱，刚度约 220 kBT/rad²，平均到每个立方体约 8 kBT/rad²。所以 **SL 的三次轴最可能沿场方向**，平均 4.8° 只是热摆动加上 sin θ 测度因子的效果（图 `sl_tilt_free_energy.png`）。
- **单个立方体的转动**：立方体只能绕 [111]（也就是场方向）扭转，而且被 steric 限制在一个 30° 宽的窗口内（`outputs/twist_window/`，图 `twist_window.png`）。
  - 在这个窗口内，集体扭转的能量 U(γ) 关于窗口中心严格镜像对称；在中心处，立方体的镜面与晶格的镜面重合。
  - 两个能量最低的状态位于窗口的两堵墙上（vdW 在那里最强），二者互为镜像。中心是能量最高点，但高出的只有 3.9 kBT（27 个立方体合计），平均每个立方体 0.15 kBT。
  - 298 K 时熵占优：窗口中心处每个立方体的笼子最宽。所以单个立方体的扭转分布以中心为峰，均值偏离中心不到 0.1°，标准差 5.8°，95 % 落在中心 ±11.6° 以内。
  - **所以室温下没有净手性**：之前报告的"所有链都朝同一方向扭转约 +15°"，是相对于 V9.03 参考取向而言的；那个参考取向恰好位于窗口的一堵墙上。立方体的 [111] 还会偏离晶格轴约 6°，方向随机。
  - 这些立方体内部的量相关时间约为 1200 cycles，3500 cycles 内没有完全收敛（R-hat ≈ 2），但在每条链中都落在同一个区间里。
- **vdW 的增强不是锐角伪影**：298 K 的末态中，没有任何一对的锐边核间距小于 0.5 nm（最小 1.2–1.75 nm）。vdW 的增加来自很多对之间距离的普遍缩小（核间距中位数从 4.24 nm 降到 2.4–3.4 nm），即立方体转到更贴合邻居的取向。
- **求积精度**：对 96 个快照用 10 倍严格求积重新计算，整体 vdW 的差最大为 1.1e−5 kBT，重加权后均值只移动 1.3e−6 kBT。

### 4.2 模拟退火（总能量最小化）

`outputs/lattice_anneal/ANNEAL_REPORT.md`，8 次独立重启：

| 量 | 8 次重启的结果 |
|---|---|
| 最低能量 | −698.7 到 −700.9 kBT（相差 2.3 kBT） |
| SL 轴倾角 | 0.06–0.32° |
| 本体 [111] 倾角 | 0.1–0.4° |
| 磁化 m_x | 0.9965 |
| 各能量项 | Zeeman −381.5，各向异性 −176.9（≈ −KV/3 × 27，即 [111] 完全对准），偶极 −87.3，vdW −53.0 到 −55.2 kBT |
| 单个立方体的扭转 | 双峰：87 % 的立方体位于窗口某一堵墙附近 8° 以内（0° 或 +31°，互为镜像）；不同重启中有 9–16 个立方体处于 +31° 墙 |

- **能量最低的构型**：SL 三次轴、本体 [111] 和磁矩都沿场方向，立方体在两种扭转之间分布。
- **8 次重启在所有取向量上都一致**，所以"SL 平行于场"是可靠的全局结论。
- **立方体扭转的最优排列是玻璃态的**：有许多近简并的极小（差别 < 0.1 kBT/立方体），几何降温无法保证找到唯一的全局最小。这些差别主要来自 vdW，其中 1.3–2 kBT 来自锐边核相距 0.17–0.34 nm 的接触，也就是 D₀ 附近的锐角理想化。所以 T = 0 下各立方体的具体扭转模式有模型依赖性。若要确定它，应该使用副本交换（parallel tempering），并改用圆角体 vdW。
- **局部检验**：对最低能量状态做 400 次极小的只允许下坡的扰动，最大单次下降为 0.002 kBT，总共 0.02 kBT，说明它确实位于局部极小。
- **与 298 K 的关系**：T = 0 时，每个立方体的扭转落在两堵互为镜像的墙之一。298 K 时，每个立方体只有 0.15 kBT 的能量差，被窗口中心更大的构型熵压过，扭转分布成为以中心为峰的宽分布。所以对室温问题，**有意义的是 4.1 节的分布，而不是退火得到的单个构型**。SL 轴平行于场这一点，在两种温度下都成立。

### 4.3 每条链的结果与区间

`outputs/lattice_per_chain/`：`PER_CHAIN_RESULTS.md`、`per_chain_sampling.csv`、`per_restart_annealing.csv`，以及图 `sl_tilt_every_chain.png` 和 `per_chain_intervals.png`。这里不依赖收敛，列出的是每条链实际到达过的范围。

- **SL 轴倾角**（SL 三次轴与外磁场 B 的夹角，0–90°）：16 条链在 warm-up 之后的所有样本都落在 0.03°–14.5° 之间，95 % 落在 0.9°–10.2° 之间；每条链 97.5 % 分位数的上界都在 8.6°–11.4° 之间。从 20°、40°、60° 出发的链，约 100 cycles 内就进入这个区间，之后再也没有离开。偏转方向（方位角）绕 B 均匀分布，所以 SL 轴是在一个以 B 为轴、半角约 10° 的锥内摆动。
- **本体 [111] 倾角**：区间与 SL 轴倾角相同，因为立方体被晶格锁住，随 SL 一起摆动。
- **单个立方体的扭转**（从 V9.03 参考取向算起）：全部落在 −2.2° 到 +32.5° 之间，95 % 在 +2.7° 到 +26.9° 之间，也就是以 +15°（镜像中心）为中心、±15° 的窗口之内；每条链中 27 个立方体的平均扭转在 +5.8° 到 +21° 之间。
- **磁化 m_x**：每条链的 95 % 区间都在 0.94–0.98 之间。
- **退火（T → 0）**：8 次重启的最优构型中，SL 倾角为 0.06–0.31°；最后 300 cycles 内不超过 1.14°。

### 4.4 与实验观测到的倾斜态比较

- 按菱方倒易点阵（a = 20.31 nm，α = 74°）计算，[1 1.4 1]\*SL 与 [111]\*SL 的夹角是 **13.7°**，而不是 10°。另外，[1 2 1]\* 是 27.3°，[1 2 0.5]\* 是 37.9°。
- 在 48 000 个样本中，SL 倾角达到或超过 13.6° 的只有 35 个（0.07 %），每单位立体角的自由能比最低点高约 6.5 kBT。
- 所以，在当前模型中，实验观测到的倾斜态**不是单个畴的热平衡状态，也不是常见的热涨落**。模型给出：无约束的单畴 SL 平行于场，热摆动 ≲ 10°。倾斜态需要模型之外的集体作用来稳定，例如浓度相关的畴间耦合、螺旋或手性超结构、场梯度。这与倾斜态随局部浓度变化的实验结果（S17）一致。

## 5. 需要注意的地方

1. **条件系综回答的是条件问题**。刚性晶格的结论只在"SL 已形成并被锁定"时成立；它不能反过来说明 SL 会形成（第 1 节）。
2. **倾角的均值不等于最优倾角**。随机方向的平均倾角也有 57°；判断最可能的方向要看 F(θ) = −kT ln[p(θ)/sin θ]，或者看 T = 0 的最小值。
3. **优化器与采样器的规则不同**。退火可以自适应调参，但需要多次独立重启并对结果做局部检验；采样必须冻结步长，并做收敛诊断。
4. **慢变量要单独判断**。能量、磁化、SL 倾角收敛了，并不等于立方体的内部扭转也收敛了。它的相关时间约为 1200 cycles，需要单独报告 R-hat，不能用最快的量来代表整体。
5. **warm-up 不能事后修改**。发现弛豫比预想的慢时，正确做法是接着跑，并事先规定新的 warm-up。
6. **小心模型伪影**。只要锐边立方体的角能在 steric 墙后面相互靠近，优化器就会去利用它（T = 0 时有 1–2 kBT）。298 K 下这种情况没有出现，但 T = 0 的细节会受影响。

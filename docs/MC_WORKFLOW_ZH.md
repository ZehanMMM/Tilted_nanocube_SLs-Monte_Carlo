# V9.04 Monte Carlo 全流程：每一步做什么、为什么、怎么验证

本文按实际执行顺序记录 V9.04 的全部工作。每一步都回答三个问题：这一步要保证 MC 的哪条假设；怎么做；用什么证据说明它成立。结果与数字见第 7–9 节，它们来自 `outputs/` 中的原始数据。

MCMC 给出的估计量是

    Ê[f] = (1/n) Σ_t f(x_t)  →  E_π[f] = ∫ f(x) π(x) dx

它要可信，需要四件事依次成立，缺一不可：

1. **目标 π 存在**：π 是一个可以归一化的概率分布（第 1 节）。
2. **能量算对**：链里用的 U(x) 就是想要的 U(x)，并且是状态的确定函数（第 2 节）。
3. **核正确**：转移核以 π 为不变分布，不可约、非周期（第 3、4 节）。
4. **有限样本够用**：链已忘记初态，且 n 足够让 MCSE 小于所需精度（第 5–8 节）。

前三条是"对不对"，第四条是"够不够"。诊断统计量只能检验第四条，而且只能证伪不能证明。前三条必须靠推导和独立基准来保证。

### 结论先行

- **vdW**：按 V10 的方法，把锐边立方体 Hamaker 积分做到体素极限。n³ 体素和按 n⁻² 收敛到快速算法的值。在 1.8 nm 面间隙下，V9.03 的 4³ 值只有收敛值的 34 %；紧凑初态整体的 vdW 为 −47.6 kBT（原为 −32.4）。
- **目标分布**：V9.03 的目标分布不可归一化，改用 Stillinger 团簇系综。第一次正式运行中，MC 找到了"锐边 vdW + 圆角 steric"组合的能量洞（−462 kBT），加入 D₀ = 0.165 nm 的核间最小距离后修正。
- **核的正确性**：27 个单元测试，包括与独立答案对照和一个负对照；drift ≤ 2e−13 kBT；步长减半后均值不变（abs(z) ≤ 2.2）。
- **收敛**：单颗粒量已收敛（本体取向随机，57.33° ± 0.34°；m_x = 0.9306 ± 0.0004）。团簇结构量（Rg、SL 倾角）没有收敛，并且由团簇定义决定：键长从 30 改为 36 nm，Rg 从 71 增加到 84 nm。
- **物理**：在这个哈密顿量下，298 K、500 G 时 27 颗粒超晶格不是束缚态，单独一对也不束缚。

## 1. 目标分布：先问"我在对哪个分布求期望？它存在吗？"

### 1.1 状态空间与参考测度

x = (r_1, …, r_26; Q_0, …, Q_26; m_0, …, m_26)

- r_0 固定。整体平移不改变能量，固定一个颗粒只是把平移零模积掉，不改变任何内部统计量。
- Q_i ∈ SO(3) 是立方体姿态，参考测度是 Haar 测度（"均匀随机转动"）。
- m_i ∈ S² 是磁矩方向，参考测度是球面均匀测度。

参考测度必须写清楚。proposal 是否"对称"是相对于这个测度而言的（第 3 节）。

### 1.2 能量

U = Zeeman + 一阶立方各向异性 + 点偶极 + steric 弹簧 + vdW。前四项与 V9.03 的公式、参数完全相同，vdW 换成 V10 的收敛积分（第 2 节）。

### 1.3 V9.03 的目标分布不可归一化

把一个非中心颗粒拿到很远处：steric 为 0，vdW 超出截断后为 0，偶极按 1/d³ 衰减，Zeeman 与各向异性有界。所以 exp(−U/kT) 在远处趋于正常数，而位置积分 ∫ r² dr 发散，**π 不是概率分布**。

这时 MCMC 没有可以收敛到的平稳分布。链只会一直漂移，任何 R-hat、ESS、MCSE 都没有意义。V9.03 的文档第 9 节已经指出这一点，但当时没有加入边界。V9.03 联合验证中 Rg 一直增大、body tilt 的 R-hat = 1.19，与此一致。

### 1.4 修正：Stillinger 团簇系综

    π(x) ∝ exp(−U(x)/kT) · 1[键图连通] · 1[锐边核间距 ≥ D₀]

- **键**：两颗粒中心距 < 30 nm（初始第一壳层为 21 nm 和 25.3 nm，8 % 膨胀初态为 22.7 nm 和 27.4 nm，都算键）。连通意味着任意两颗粒距离 ≤ 26 × 30 nm，状态空间有界，π 可归一。这是团簇模拟中的标准定义（Stillinger 1963；也用于成核团簇自由能）。
- **硬核**：vdW 积分作用在锐边立方体上。两锐边核重叠时积分发散，所以这些状态本来就是零权重。此外还要求锐边核之间至少相距 D₀ = 0.165 nm（Hamaker 理论的标准接触截断距离，Israelachvili）。这一条不是可有可无的，原因见 2.7 节：没有它，目标分布同样不可归一化。判断时先用分离轴定理（15 个候选轴）排除绝大多数对，只有它无法排除的少数对才计算精确最小距离（有界最小二乘）。
- **键长是模型选择，不是采样技巧**。所以它必须做敏感性检验（第 8 节：30 → 36 nm）。若结果随键长明显变化，说明约束在起作用，结论依赖于"团簇"的定义。

> 面试要点：写任何 MC 之前先写出被积函数和测度。若 ∫ π = ∞，采样器再好也没用。

## 2. 能量函数：MC 只会忠实地采样你给它的能量

### 2.1 V10 的方法是什么

V6.20/V9/V10 都在算同一个积分：

    U_vdW = −(A/π²) ∫_{cube1} ∫_{cube2} dV₁ dV₂ / |r₁ − r₂|⁶

V9.03 用 4³ 中点体素并加了 d² ≥ 1e−19 m² 的下限。V10 最新的做法（`rotational_entropy_model.central_vdw`）是把同一个体素和去掉下限、加密到不再变化。所以"按 V10 方法"就是：**同一个锐边立方体积分，取体素数 n → ∞ 的极限**。

### 2.2 为什么 4³ 不收敛

体素边长 4 nm，而 V9 的面间隙只有 1.8 nm。1/r⁶ 核在一个体素内变化几个数量级，中点公式的误差 ~ (h/gap)² 不是小量。面对面 1.8 nm 时，4³ 只得到收敛值的 34 %（2.91 倍差距）。

### 2.3 快速且严格的算法

直接加密体素是 O(n⁶)：n = 32 时一对就要 30 s，无法放进 MC。用两次散度定理（R = r₂ − r₁）：

    r⁻⁶ = −(1/3) ∇₂·(R R⁻⁶),        (n₂·R) R⁻⁶ = ∇₁·(n₂ R⁻⁴ / 4)

6 维体积分就精确地变成 36 个面对的面积分

    ∫∫ dV₁dV₂ / r⁶ = −(1/12) Σ_{i,j} (n_i·n_j) ∫_{F_i}∫_{F_j} dS_i dS_j / R⁴

内层 ∫_{F_j} R⁻⁴ dS 对正方形有闭式解，只剩外层 2 维积分用 Gauss 求积。锐边、锐角相距很近的面对用自适应细分，接受一个面板需要满足以下两者之一：

- **几何条件**：面板半径 ≤ 0.5 × 它到另一面的距离下界；
- **数值条件**：面板半径 ≤ 4 × 该距离，并且父面板与四个子面板的结果之差小于容差。

只看数值的自适应规则有一个固有漏洞：宽度小于节点间距的尖峰，父面板和子面板都看不到，于是二者"一致"地给出错误结果。几何条件从原理上排除了这种情况。这里没有任何拟合或插值。

### 2.4 证据：它就是体素和的极限

`outputs/vdw_convergence/`（无下限的 n³ 体素和，括号内为相对收敛值的误差）：

| 情形 | n = 4 | n = 16 | n = 32 | n = 128 | 收敛值 / kBT |
|---|---|---|---|---|---|
| 平行面对面，间隙 1.8 nm | −2.573 (−66 %) | −6.437 (−14 %) | −7.179 (−4.2 %) | −7.474 (−0.28 %) | −7.495 |
| 平行面对面，间隙 3.0 nm | −1.186 (−47 %) | −2.091 (−6.4 %) | −2.195 (−1.7 %) | −2.232 (−0.11 %) | −2.234 |
| V9.03 初态最强一对（转动姿态） | −0.492 | −0.711 | −0.730 (−0.9 %) | | −0.737 |
| 倾斜近接触，核间距 1.0 nm | −0.498 | −0.843 | −0.892 (−2.2 %) | | −0.912 |
| 整个紧凑初态 351 对之和 | −32.48 | −46.06 (−3.3 %) | | | −47.64 |

- 所有情形的误差都按 n⁻² 下降，与中点公式的理论阶数一致（图 `vdw_voxel_convergence.png` 左）。
- 用最细两级做 h² Richardson 外推，误差继续下降到 1e−5–1e−4，并且收敛到快速算法的值（右图）。
- 3 nm 面对面的极限是 −9.196e−21 J。V10 审计中引用的 −9.156e−21 J 是有限 n 的值，比极限浅 0.4 %。

### 2.5 精度预算

- 默认设置下，每个面对的容差为 1e−5 kBT。在 5132 个近接触、倾斜的基准对上，与极严格参考值的最大误差是 8.0e−8 kBT（只用数值条件时为 4.6e−6）。
- 另外用一个完全独立的方法核对：把体积分本身做八叉树细分，只按几何距离决定是否细分，与面积分方法不共享任何代码。3 nm 面对面时两者相差 3.6e−6；锐边核间距 0.165–1 nm 时相差 < 2e−3（八叉树本身的精度）。
- 能量误差 ≪ kT，也 ≪ 能量均值的 MCSE，因此对采样结果的影响可以忽略。第 8 节用生产快照的重加权直接验证了这一点，而不是只凭估计。

### 2.6 其余能量项和增量能量

- Zeeman、各向异性、偶极、steric、初态构造与 V9.03 notebook 源码逐项比较，一致到 1e−9 相对精度（`tests/test_model.py`）。
- 每次 move 只重算受影响的项（ΔE）。每 250 cycles 从头计算一次总能量并与缓存值比较（drift），超过 1e−6 kBT 就判为失败。
- **一个必须避免的隐患**：能量必须是状态的确定函数。自适应求积对交换两个立方体、或对整体刚体转动，只在容差内不变（~1e−5 kBT），不是逐位不变。若共旋转后直接沿用缓存 vdW，或单颗粒更新时以不同的顺序计算同一对，链的"能量"就会依赖历史，MH 的目标不再是一个固定的 π。现在所有对都按"编号小者在前"计算，共旋转也重算 vdW。修正后缓存值与从头计算逐位相同（drift = 0.0）。

### 2.7 MC 找到了能量函数的"洞"

第一次正式运行时，16 条链中有 1 条在约 2800 cycles 处 vdW 从 −125 kBT 突降到 −462 kBT，并且再也没有出来。追查过程：

1. **定位**：几乎全部的变化来自一对颗粒：W = −458 kBT，而粗体素和只有 −0.27 kBT。两个锐边核的最小距离是 1.5e−5 nm，但 steric 使用的圆角支撑间隙读数为 1.86 nm，满足约束。
2. **先怀疑数值**：用独立的八叉树体积分重算，得到同样的数值（0.01 nm 时两者都是 −10.97 kBT，0.05 nm 时都是 −1.500 kBT）。所以这**不是求积误差，而是这个模型本身的积分值**。
3. **原因**：steric 用的是圆角立方体，而 vdW 积分用的是锐边立方体。锐角比圆角体最多凸出 (√3 − 1) × 1.5 = 1.1 nm，所以两个锐角可以在 steric 允许的情况下相互接触。这一对中，两个接触点都靠近顶点，旁边的两个面只相差 12°，构成一道很薄的楔形缝，吸引能大约按 1/δ 增长。∫ exp(+c/δ) dδ 在 δ → 0 处发散，**目标分布在这些接触构型附近不可归一化**。链一旦进入，就不会再离开。
4. **修正**：要求锐边核间距 ≥ D₀ = 0.165 nm（Hamaker 标准接触截断）。在该距离上这一对只有 −0.44 kBT，能量有界，π 可归一。随机采样 600 个贴着 steric 墙的构型，加上 D₀ 后最强的吸引只有 −1.25 kBT，只有 2.7 % 的墙面接触其锐边核距离在 0.5 nm 以内。所以这条约束只去掉了极小的一块构型空间，不会自己成为新的主导作用。
5. **后续处理**：第一次运行整体作废，存档为 `outputs/production_v1_energy_hole/`。16 条链以它们的末态（掉进洞的那条链用洞之前的 1300-cycle 快照）作为弛豫起点，在修正后的目标下用新 seed 继续运行（第 6 节）。

教训：

- MCMC 会系统性地去找能量最低的地方，所以任何让能量趋于 −∞ 的漏洞，它迟早都会找到。
- 要追查到底是数值问题还是模型问题，必须用独立的方法重算。
- 按初态分组的诊断（这条链所在初态的 vdW 标准差达到 88 kBT）和逐链检查才让这个问题暴露出来。只看合并后的均值是看不出来的。

## 3. 转移核：细致平衡是怎么保证的

### 3.1 Metropolis–Hastings

    α(x → x') = min{1, [π(x') q(x | x')] / [π(x) q(x' | x)]}

q 对称时，比值只剩 exp(−ΔU/kT)。被拒绝时**留在原状态并照常记录**。删掉拒绝的样本会使分布偏向高接受区域。

### 3.2 每种 move 的对称性论证

| move | proposal | 为什么对称 / Hastings 因子 |
|---|---|---|
| 平移 | r_i + U(−s,s)³，i ≠ 0 | 位移分布关于 0 对称，因子为 0 |
| 本体转动 | exp(θ[n]) Q_i，n 均匀，θ ~ U(−s,s) | 转动 R 的分布只依赖转角（类函数）且 R 与 R⁻¹ 同分布，所以相对 Haar 测度对称 |
| 磁矩 | 同样的小转动作用于 m_i | 核在旋转下协变，密度只依赖 m·m'，对称 |
| 两尺度混合 | 以固定概率 1/2 选小步或大步 | 选择与状态无关，对称核的混合仍对称 |
| 共旋转 | 所有 r、Q 绕 r_0 同一刚体转动 | 转动保持 Lebesgue 与 Haar 测度，R 与 R⁻¹ 同分布 |
| 共扭转 γ | 所有 Q 绕平均 [111] 轴 a(Q) 转 θ | 见下文 |
| 整体缩放 | r_0 + e^ε (r − r_0)，ε ~ U(−s,s) | 映射的 Jacobian 为 e^{3(N−1)ε}，接受率中加 3(N−1)ε = 78ε |

**共扭转的细节**：转轴依赖状态，这类 move 需要单独检查。

- (a) 反向 proposal 必须用同一个轴。旋转后平均轴 R_a a = a 不变，所以反向就是同轴 −θ，密度相同。
- (b) 依赖状态的映射 Q ↦ R_{a(Q)}(θ) Q 必须保测度。它是向量场 V = Σ_k a_k(Q) X_k 的流，其中 X_k 是左乘转动的生成元。div V = Σ_k X_k(a_k)。由于 a(GQ) = G a(Q)，有 X_k(a) = e_k × a，其第 k 分量为 0，所以 div V = 0，映射保持乘积 Haar 测度，Jacobian = 1。

两条都成立，接受率里不需要额外的因子。

### 3.3 约束的正确处理：拒绝，不是重抽

违反连通或硬核的 proposal 等价于 ΔU = +∞，直接拒绝并留在原地。"反复抽样直到满足约束"会改变 proposal 密度，而且不再对称，从而破坏细致平衡。报告中单独统计了被约束拒绝的比例（blocked）。

### 3.4 组合与随机顺序

每个核单独保持 π 不变，所以它们的复合也保持 π 不变。每个 sweep 的颗粒顺序是与状态无关的随机排列，相当于复合核的混合，仍保持 π。整个 cycle 不可逆，但 MCMC 只需要 π 是不变分布，不需要可逆。

### 3.5 不可约与非周期

平移、转动、磁矩三类 move 分别覆盖全部自由度，且步长有限，理论上可以到达任何允许状态。存在拒绝，所以链是非周期的。但**理论上不可约不等于实际混合得动**：亚稳构型可能要很长时间才离开。这只能用多初态、多 seed 的诊断来检查（第 7 节）。

### 3.6 为什么生产中不能自适应调参

用链自己的历史调步长会使链不再是马尔可夫链，遍历定理的前提被破坏（只有满足 diminishing adaptation 等额外条件时才可以）。所以步长只在 pilot 中调，之后冻结。pilot 样本全部丢弃，生产使用新的 seed。

## 4. 用独立答案检验每个核

链内自洽（ΔE 正确、接受率合理）并不能说明采到了正确的分布：漏掉一个 Jacobian 的链看起来完全正常。因此每种 move 都拿到一个有独立答案的问题上检验，要求 |MCMC 均值 − 答案| < 4 × MCSE。

| 测试 | 独立答案 | 结果 |
|---|---|---|
| K = 0 时的本体转动 | Haar 测度解析值 E[cos ω] = −1/2 | 通过 |
| 单磁矩（Zeeman + 立方各向异性） | 球面 Gauss–Legendre × 均匀 φ 数值积分 | 通过 |
| 两立方体平移（vdW + 偶极 + steric + 约束） | 同一分布的 i.i.d. 重要性抽样（ESS > 1500） | 通过 |
| 平移 + 缩放混合 | 同上 | 通过 |
| 仅缩放、沿固定射线 | 一维数值积分 ∝ s² exp(−U/kT) | 通过 |
| **负对照**：缩放去掉 Jacobian | 同上 | 被检出（偏差 > 5 MCSE，且恰好落在不含 s² 的错误答案上） |
| AR(1) 序列 | τ = (1+φ)/(1−φ) 精确值，MCSE 解析值 | 通过 |
| 近接触 vdW（锐边核相距 0.165、0.3 nm） | 独立的八叉树体积分 | 相差 < 2e−3，通过 |
| D₀ 约束 | 锐边核相距 0.10 / 0.16 nm 必须被排除，0.17 / 0.40 nm 必须允许 | 通过 |

负对照很重要：它证明这个测试有能力发现错误，而不仅仅是碰巧通过。有一点需要注意：若用真实的 7 kBT 接触势，颗粒一直贴着接触面，漏掉 s² 只移动均值不到 1 个 MCSE，测试就检不出来。所以检验核时要故意选择对错误敏感的问题（这里把势阱调浅）。

全部 27 个单元测试见 `tests/`，运行 `python -m unittest discover -s tests -v`。

## 5. 参数调节（pilot，样本不进入结果）

### 5.1 Pilot 1：弛豫

从晶格初态出发的前几百 cycles 是瞬态，不能用来调步长。四个初态各跑 300 cycles，只保留末态。40° 初态在约 200 cycles 内倾角降到约 5°，与 0° 初态一致。但所有链的 Rg 都在增大，vdW 在减弱：这是后面物理结论的第一个信号。

### 5.2 Pilot 2：步长阶梯，以 MSJD 评分

    MSJD = Σ(被接受跳跃²) / 尝试次数 = 接受率 × E[跳跃² | 接受]

对随机游走 proposal，MSJD 最大基本等价于一阶自相关最小。步长太小时几乎全接受但走不动，太大时几乎全被拒。每次尝试的计算成本几乎与步长无关，所以取 MSJD 的最大值。

- 第一轮 ×{1/4, …, 4}：平移、转动、共旋转、缩放的最优都落在 ×4 的**边界**上。**最优点在网格边界时不能直接取边界值**，必须外扩网格。
- 第二轮 ×{4, …, 64}（与第一轮在 ×4 处重叠，可检查重复性）：

| move | V9.03 步长 | 最优倍数 | 选用步长 | pilot 接受率 | 生产接受率（被约束拒绝的比例） |
|---|---|---|---|---|---|
| 平移 | 0.03 nm（与转动合为一个 move） | ≥ 64（仍在边界，但 49 % 已被约束拒绝） | 0.4 nm / 6.4 nm 两尺度混合 | 0.40 | 0.53（0.26） |
| 本体转动 | 2° | ≥ 64 | 8° / 128° 两尺度混合 | 0.36 | 0.60（0.03） |
| 共旋转 | 3° | 4 | 12° | 0.36 | 0.40（0） |
| 共扭转 γ | 2° | 1（1–4 倍间是平台） | 2° | 0.46 | 0.65（0） |
| 缩放 | 0.002 | 16 | 0.032 | 0.12 | 0.13（0.33） |

生产中的接受率比 pilot 高，是因为团簇变得更松了。步长减半的检验（第 8 节）说明这次调参是有意义的：步长减半后，本体倾角的相关时间从约 19 cycles 增加到约 180 cycles，MCSE 从 0.34° 增加到 2.4°，而均值不变。

V9.03 的机械步长比最优小 1–2 个数量级，这是它混合很慢的原因之一。

### 5.3 两尺度混合

pilot 期间团簇还在变松，大步长的 MSJD 是在越来越松的状态上测的，会偏向大步。所以平移和转动每次以 1/2 概率用小步（×4）、1/2 概率用大步（×64）。若团簇变松，大步有效；若团簇变紧，小步仍然有效。这种混合保持对称性，不改变目标。

### 5.4 磁步长沿用 V9.03 的标定

给定几何时，磁矩的条件分布只含 Zeeman、各向异性和偶极项，**不含 vdW**。所以 V9.03 在固定几何上的磁标定（1.60 rad，每 cycle 10 个完整 sweep；232 项检查全部通过）对 V9.04 仍然成立，不需要重新调。

## 6. 生产运行设计

- **过度分散的初态**：紧凑/膨胀 × 0°/40°。R-hat 只有在链从真正不同的地方出发时才有检出力。
- **每个初态 4 个 seed**，共 16 条链。第一次运行（v1）每条 3000 cycles，从晶格出发，这些链已经在 v1 中从不同初态弛豫过。v1 因 2.7 节的问题作废，改为从 v1 的末态继续运行 4000 cycles（v2），并使用新的采样 seed（11–14）。
- **随机数**：`SeedSequence([seed, start_id]).spawn(2)` 为每条链生成独立的初始化流和采样流。pilot、v1、v2、稳定性检验的 seed 互不重复。
- **warm-up 在看结果之前定为 1000 cycles**，之后用 MSER-5 与 Geweke 检查这个选择，而不是根据结果去挑 warm-up。
- **不做 thinning**。thinning 只会丢信息，它的唯一用途是节省存储。
- 每 100 cycles 保存完整构型，每 250 cycles 做一次 drift 检查。每条链结束时检查：drift ≤ 1e−6 kBT，轨迹有限，末态满足约束，vdW 自适应求积从未碰到最大细分层数。任何一项不满足，这条链就被判为失败。

## 7. 收敛诊断

（结果见下，数字来自 `outputs/production/REPORT.md`。）

每个诊断量回答一个具体问题：

| 诊断量 | 回答的问题 | 通过标准 |
|---|---|---|
| rank-normalized split R-hat | 不同链、以及每条链前后两半是否在采样同一个分布 | < 1.01 |
| bulk / tail ESS | 相关样本相当于多少个独立样本（分布主体 / 5 % 与 95 % 分位） | ≥ max(400, 100 × 链数) |
| MCSE（ArviZ） | 由有限样本造成的均值误差 | 小于所需精度 |
| 批均值 MCSE | 用另一种估计量得到的同一个量；与 ArviZ 不一致时误差条不可信 | 与 ArviZ 同量级 |
| τ_int（Sokal 自洽窗口） | 每隔多少 cycles 得到一个独立样本；n > 50τ 时 τ 本身才可靠 | tau_reliable |
| Geweke z | 保留窗口开头 10 % 与末尾 50 % 的均值是否不同 | abs(z) < 2–3 |
| MSER-5 | 初始化偏差大约在哪里结束 | < 固定的 warm-up |
| 按初态分组的分布 | 不同初态的保留样本是否给出同一个直方图 | 目视加分组诊断 |

记住：诊断全部通过也不是收敛的证明（所有链可能都困在同一个亚稳态），但只要有一项失败，就说明一定有问题。

## 8. 稳定性与敏感性检验：先想清楚每个检验"应该"得到什么

| 检验 | 改变了什么 | 目标分布是否改变 | 预期 |
|---|---|---|---|
| 步长减半 | 所有机械和集体步长 × 1/2 | 否 | 均值在 MCSE 内一致（abs(z) ≲ 2），只有效率变化 |
| 求积精度 | 生产快照用严格 10 倍的求积重算 vdW | 几乎不变 | 能量差 ≪ kT，重加权后的均值不变 |
| 团簇定义 | 键长 30 → 36 nm | 是 | 若结果不变，说明约束"不起作用"，团簇是自束缚的；若明显改变，说明结论由约束决定 |
| vdW 模型 | 换回 V9.03 的 4³ 体素 | 是 | 量化这次 vdW 更新对物理结果的影响 |
| 初态 / seed | 4 个初态 × 4 个 seed | 否 | 各初态的分布一致（按初态分组的 R-hat 与直方图） |
| warm-up | 事先固定 1000 cycles | 否 | MSER-5 截断点 < 1000，Geweke abs(z) 不系统性偏大 |

z = (变体 − 参考) / sqrt(MCSE_参考² + MCSE_变体²)。对"目标不变"的检验，abs(z) ≫ 2 说明两次运行中至少有一个没有收敛，或某个核有错误；对"目标改变"的检验，z 衡量的是结论对该建模选择有多敏感。z 只有在两次运行各自通过收敛检查时才有意义。

### 8.1 结果

`outputs/stability_comparison.md`。变体各有 4 条链，从 v2 生产链的末态接着跑，使用新 seed。

| 观测量 | 生产 | 步长减半 z | 键长 36 nm z | V9.03 vdW z |
|---|---|---|---|---|
| 本体倾角 | 57.33° ± 0.34° | −0.90 | +0.31 | −0.68 |
| 本体取向序 | 0.176 ± 0.0014 | +0.87 | +0.93 | −0.67 |
| 磁矩–本体夹角 | 90.3° ± 0.2° | +0.43 | −1.45 | −1.20 |
| 磁化 m_x | 0.9306 ± 0.0004 | +0.34 | +0.25 | +2.34 |
| SL PCA 倾角 | 12.6° ± 1.6° | −0.78 | +0.30 | −1.79 |
| vdW | −4.89 ± 0.06 kBT | +1.81 | **+16.7**（−3.09） | **+15.2**（−3.39） |
| 总能量 | −570.6 ± 1.1 kBT | +0.68 | **+11.0** | −0.34 |
| Rg | 71.0 ± 2.0 nm | −1.23 | **+4.4**（83.6 nm） | +0.95 |
| 键数 | 29.5 ± 0.2 | −0.70 | **+5.9** | +0.60 |
| 最小间隙 | 1.898 ± 0.001 nm | +2.19 | **+9.9** | +3.28 |

- **步长减半**（目标不变）：10 个观测量的 abs(z) 全部 ≤ 2.2，与纯抽样噪声一致。改变采样器不改变答案，这是对核正确性的又一次独立检验。
- **键长 30 → 36 nm**：凡是描述团簇结构的量都显著改变（Rg 增加 12.6 nm，vdW 减弱 37 %），而单颗粒量（取向、磁化）完全不变。**团簇的结构由"团簇"的定义决定，而不是由相互作用决定。**
- **换回 V9.03 的 4³ vdW**：vdW 能量弱 1.44 倍（z = +15），其余量基本不变。这次 vdW 更新在数量上是必要的，但不改变定性结论。
- Rg、键数、SL 倾角在所有运行中都没有收敛（R-hat 1.75–2.45），所以它们的 z 只能作为方向性的参考。结论"团簇结构由定义决定"依据的是 z = +4.4 到 +16.7 的一致变化，加上 26–33 % 的 move 被约束拒绝，而不是某一个 z 值。
- **求积精度**（重加权，128 个生产快照）：生产求积与 10 倍严格求积的能量差最大只有 3.8e−7 kBT，权重在 1 ± 2e−7 之内，重加权后 vdW 均值只移动 2e−7 kBT。求积误差可以完全忽略。

## 9. 物理结论

1. **在 V9 的哈密顿量下（298 K，500 G，16 nm 立方体，A = 2e−20 J，1.8 nm steric 间隙），27 颗粒超晶格不是自束缚的。** 所有链从晶格出发，约 300 cycles 内键数从 90 降到约 30（26 就是生成树的最小值），vdW 从 −47.6 降到约 −5 kBT。无论初态、seed、步长、vdW 版本如何，都是这个结果。
2. **单独一对也不束缚**（`outputs/pair_binding/`）：同一系综中，两颗粒处于"接触"（steric 间隙 < 2.5 nm）的时间，在 30 nm 球内为 24 %，在 36 nm 球内为 14 %；接触时的平均 vdW 只有 −0.3 至 −0.4 kBT。接触概率随可用体积变化，说明接触不是一个独立的束缚态。面对面 1.8 nm 时虽然有 −7.5 kBT 的 vdW，再加上偶极吸引，但这需要精确对准位置和取向，其熵代价更大。
3. **可信的数值只有单颗粒量**：本体取向完全随机（相干倾角 57.3°，取向序 0.176，都等于随机取向的期望值）；磁矩沿场排列，m_x = 0.9306 ± 0.0004。它们对所有稳定性检验都不敏感。
4. **SL 倾角、Rg、键数不是超晶格的性质**：它们随键长定义显著变化，并且在 7000 cycles 内仍在漂移（Rg 的 R-hat = 2.45）。任何 V9 系列中关于"SL 倾角"的数值，都依赖于初态附近的亚稳停留时间，或者依赖于团簇的定义。
5. **与 V10 记忆中的结论一致**：vdW 的大小是关键的未定量。V13 的 npvdw 在 3 nm 面对面时给出 −2.056e−20 J，是这里收敛值（−9.196e−21 J）的 2.2 倍、V9.03 4³ 值的 4.2 倍（差别来自圆角超椭球体、不同的尺度与排斥项）。在更强的吸引、更低的温度或更大的颗粒下，超晶格才可能成为束缚态，这可以用同一套程序直接扫描。

## 10. 局限

- vdW 积分沿用 V10 的**锐边立方体**，而 steric 用的是圆角立方体的支撑函数。锐边的角和棱最多比圆角体凸出 (√3 − 1) × 1.5 = 1.1 nm，所以两者描述的颗粒形状不同。这是 V10 方法本身的设定，这里没有改动。
- steric 间隙沿中心连线计算，是真实间隙的下界。这与 V9.03 相同。
- 团簇定义（键长）是一个物理选择。第 8 节给出了结论对它的敏感度。若要研究有限浓度下的组装平衡，应改用有限容器，并加入团簇–单体交换的 move（例如 aggregation-volume-bias MC）。
- vdW 快速算法只适用于满足 D₀ 的状态。锐边核相距远小于 D₀ 时，几何细分会变得非常深，内存开销急剧增加（单元测试中的重要性抽样参考就因此改为同样使用 D₀ 约束）。
- MC 的 cycle 不是物理时间，不能用来讨论动力学。

## 11. 面试式速查清单

1. **估计的是什么？** 写出 E_π[f]、状态空间和参考测度；检查 ∫π < ∞。
2. **被积函数算对了吗？** 数值积分要做收敛研究（n → ∞、Richardson 外推），不能只信一个默认分辨率；误差预算要远小于 kT 和 MCSE。
3. **能量是状态的确定函数吗？** 缓存、增量更新、自适应算法都可能让能量依赖历史，要用 drift 检查逐位对照。
4. **proposal 对称吗？** 对称是相对于参考测度而言的。依赖状态的映射要检查 Jacobian（缩放是 e^{3(N−1)ε}，共扭转的散度为 0）。
5. **约束怎么处理？** 拒绝并留在原地，不能重抽；拒绝的样本要保留。
6. **怎么知道核是对的？** 找一个有独立答案的问题（解析解、数值积分、i.i.d. 重要性抽样），并用负对照证明测试确实能发现错误。
7. **调参放在哪里？** 只在 pilot 中调，之后冻结，并使用新 seed；最优点落在网格边界时要外扩网格。
8. **怎么设计生产运行？** 过度分散的初态、独立随机流、事先固定的 warm-up、不 thinning、检查点。
9. **怎么判断够不够？** R-hat、bulk/tail ESS、MCSE（两种估计量）、τ_int、Geweke、MSER、按初态比较分布。诊断只能证伪。
10. **稳定性：** 只改采样器的检验结果必须不变；改模型的检验衡量敏感度。
11. **报告：** 均值 ± MCSE，并写明哪些检查通过、哪些没有；失败的诊断不删、不改阈值、不靠 thinning 修饰。

# V9.03 采样实验与诊断

本次更新只修改采样、初态设计、诊断与输出。vdW、磁相互作用和排斥势的公式及参数保持不变，未添加构型熵能量项。旧 PDF 和 SI 保持原样。2026-09-15 的正式实验位于 `outputs/sampling_2000cycles_20260915/`。

## 1. 磁更新数量

`N_MAG_PER_CYCLE = 10` 表示每个 MC cycle 做 10 个完整磁 sweep。每个 sweep 都按新的随机排列访问全部 27 个颗粒，每个颗粒尝试一次磁矩旋转。原先按有放回抽样选颗粒，单个颗粒可能在一个 cycle 内被访问多次或一次也没有被访问。

磁更新现在只计算 Zeeman、各向异性和偶极能量。磁矩改变时，位置与本体姿态不变，因此 vdW 与排斥项在能量差中抵消。这个优化不改变磁相互作用模型。

旧版本的 5 sweeps 和 0.30 rad 是暂定值。正式条件试跑比较了 0.30、0.80、1.60 rad 与 1、5、10 sweeps 的九组组合，共 144 条链，每条 2000 cycles。只有 1.60 rad、10 sweeps 通过该试跑全部 232 个几何/变量组合的检查，最大 R-hat 为 1.0079，最小 bulk ESS 为 583.3。因此前部默认改为这组参数，它是本次候选范围内的条件标定结果，不代表联合体系的普适最优。独立 seeds 21–24、每链 4000/1000 cycles 的磁验证随后也通过全部 232 项检查，最大 R-hat 为 1.0030，最小 bulk ESS 为 1129.0。

设置 `RUN_MAGNETIC_PILOT = True`，仍可比较 `MAGNETIC_SWEEP_CANDIDATES = [1, 5, 10]`，但 notebook 内该开关执行联合采样试跑。独立的固定几何标定使用下述命令行脚本的 `conditional` 模式。所有试跑不与正式验证样本合并，也不在运行中自动修改参数。

只有全部监测变量通过诊断的候选才会参与推荐。评分采用各变量中最低的 bulk ESS/秒，时间包括 warm-up。若均不合格，输出空推荐，不能仅凭速度决定更新数量。正式比较还应考虑运行时间波动，必要时重复试跑。

## 2. 初态与随机种子

默认采用 5 种初态与 4 个 seed 的笛卡尔积，共 20 条链。旧实验仍保留原来的 3 种初态和 12 条链：

- `compact_aligned`：紧凑 cluster，body 和 SL 初始 tilt 均为 0°。
- `compact_tilted`：整体共同旋转 20°，颗粒相对位置不变。
- `expanded_tilted`：初始中心坐标扩大 8%，整体共同旋转 40°。
- `compact_tilted40`：紧凑 cluster，共同旋转 40°。
- `expanded_aligned`：初始中心坐标扩大 8%，共同 tilt 为 0°。
- `MULTI_SEEDS = [1, 2, 3, 4]`。

第三种初态改变了颗粒间距，因此不只是整体姿态不同。这些初态仍属于当前 27 颗粒 cluster 类型，不能代表所有组装拓扑。所有链的 Hamiltonian 相同，膨胀仅作用于初始坐标，不改变 `A_NM` 或 vdW 截断。

新增两种初态与原来的 0° 紧凑和 40° 膨胀初态组成 2 × 2 设计，可以分别比较间距与倾角。保留旧结构 ID，新结构只追加，避免改变旧 seed 流的含义。

初始化与采样分别使用 NumPy `SeedSequence([seed, structure_id, stream_id])`。其中 structure_id 是结构在 `INITIAL_STRUCTURES` 中的位置，stream_id 分别为 0 和 1。实际序列参数保存在 chain CSV 中，可以复现。

多链默认关闭。开启 `RUN_MULTI_SEED_SCAN` 才会运行完整实验。不同结构一起比较时，两类机械自由度必须都允许运动，否则不同链可能对应不同的条件分布。

## 3. Metropolis–Hastings

目标权重为 `exp(-U/kBT)`。接受概率是：

`min(1, exp(-delta_U/kBT + log_q_reverse - log_q_forward))`

当前随机平移、随机轴小角旋转和全局旋转 proposal 都是对称的，因此 log proposal ratio 为 0。这时 MH 就退化为原来的 Metropolis 接受率，使用 MH 名称不意味着目标分布发生变化。若以后加入不对称 proposal，必须传入正确的反向/正向密度比。

新增整体缩放 proposal 使用 `epsilon ~ Uniform(-s, s)`，将非中心颗粒位置变为 `anchor + exp(epsilon) * (position - anchor)`。中心固定，26 个自由中心有 78 个 Cartesian 坐标，接受步骤的 log 修正为 `78 * epsilon`。忽略这项会错误偏向收缩。它维持原有位置采样测度，没有向 Hamiltonian 添加构型熵能量项。

缩放不改变 cube 尺寸、本体姿态或磁矩。它保留整体方向，只改变相对中心距离。重叠仍按原有 steric 势处理。`MOVE_POSITIONS=False` 时该 move 关闭。前部参数 `GLOBAL_SCALE_MOVES_PER_CYCLE=1`、`GLOBAL_SCALE_LOG_STEP=0.002` 控制该提议。整体 co-tilt 步长增加到 3°，位置与本体仍一起旋转，接受概率仍按完整能量差计算。

代码在 log 空间判断接受，避免直接计算巨大指数。当前没有在正式采样期间自适应修改步长。连续被拒绝的状态仍按 cycle 保存，不能删除拒绝样本。

## 4. 三类统计量的含义

### Rank-normalized split R-hat

正确名称是 rank-normalized，而非 rand-normalized。它先把每条链分成前后两半，再对合并样本做秩正态化，比较链内与链间差异。ArviZ 的 rank 方法还包含 folded 检查，可以发现分布宽度的差异。

- 接近 1：目前没有发现明显的链间不一致。
- 明显大于 1：不同链或前后半链仍有差异，可能尚未混合。
- 默认门槛：小于 1.01。

该门槛不是收敛证明。所有链困在同一个未被识别的局部构型，也可能得到接近 1 的结果。

### ESS

ESS 是有效样本数。MC 样本彼此相关，1500 个 cycle 不一定有 1500 个独立样本的信息量。

对稳定链，直观近似是：

`ESS = 样本总数 / (1 + 2 * 自相关系数之和)`

本项目分别输出：

- bulk ESS：分布主体的采样信息量，采用秩转换。
- tail ESS：5% 与 95% 分位附近的采样信息量，报告两者中较小值。
- mean ESS：针对原始变量均值的有效样本数，用于解释均值精度。

三者不能互相替代。当前门槛是 `max(400, 100 × 链数)`，避免增加链数后仍用不变的低门槛。旧实验使用的 400 门槛记录在其 metadata 中，不追溯改写。真正需要多少仍取决于目标精度。ESS 可以因负自相关略大于原始样本数，不应机械截断。

### MCSE

MCSE 是 Monte Carlo standard error，即由有限采样导致的估计误差。本项目计算均值的 MCSE，其直观形式为：

`MCSE(mean) ≈ 样本标准差 / sqrt(mean ESS)`

例如平均 tilt 为 12°，MCSE 为 0.4°，表示这个均值估计的采样误差约为 0.4°。不表示所有颗粒都在 12±0.4° 之间，也不包括物理参数、几何近似或未收敛造成的误差。

默认要求 body tilt 和 SL tilt 的 MCSE 不超过 0.5°。这是可修改的精度目标，不是已达到的实验结果。

## 5. 数据如何组织

每个变量保留 `(chain, draw)` 数组。每条链分别去掉前 `MULTI_EQUIL` 个样本，不进行 thinning。不能把不同链首尾相接后当作一条链，也不能只拿每条链的均值计算 R-hat。

诊断分别在以下两层计算：

1. 所有初态和 seed 合并。
2. 每一种初态内部的各个 seed。

第一层用于检查初态依赖，第二层辅助区分初态差异和同一初态下的采样波动。结果保存在 diagnostics CSV 的 scope 字段。

少于两条链、每链少于 100 个保留样本、恒定链或非有限值会产生明确标记，诊断值记为不可用。至少四条链才允许通过最终检查。恒定链不会被报告为“MCSE 为零，因此已经精确收敛”。

固定几何标定中 body tilt、SL tilt 与位置本来就被冻结，因此不对它们计算 R-hat。该模式只诊断发生更新的磁变量。CSV 中未设置的 `mcse_target` 可以为 NaN，它表示没有单独指定精度阈值，不表示观测轨迹或 MCSE 计算失败。排查时应同时查看变量名、`status` 和具体字段，不能把所有 NaN 都替换成零。

NPZ 保存所有 cycle 的轨迹和最终状态。JSON 保存实际运行时的参数。最后一个 notebook cell 根据内存中的 `multi_bundle` 重新导出，采用原始运行设置，不会因之后修改前部参数而伪装成另一个实验。

## 6. 修正的观测量与控制行为

- local beta 现在是磁矩与自身 body [111] 的有向夹角，范围为 0–180°。旧实现实际测量 body–field 夹角。
- body–SL mismatch 现在是 coherent body tilt 减去 SL PCA tilt，可能为负。
- 两条轴的实际夹角作为独立字段保留，不能由 tilt 差值代替。
- 有符号磁化与绝对磁场对齐量同时保存。
- 位置或姿态开关关闭时，全局 move 也遵守限制。
- 中心位置仍固定，但中心颗粒的本体方向现在可以局部旋转。
- `include_vdw=False` 时，初始化与所有能量差使用同一开关。

这些修改使当前输出与定义一致，但不改变相互作用势。旧报告中的字段不应直接与新字段混用。

## 7. 本次验证与后续实验

回归测试覆盖磁能量局部差值与完整差值一致性、每个 sweep 的更新次数、开关、种子复现、不对称 proposal 的 MH 分布、短链状态、独立正态样本、偏移链、自相关链、报告导出和 notebook 格式。

另用固定邻居下单个磁矩的球面数值积分核对 MH 均值，用 78 维高斯径向分布核对整体缩放的 Jacobian。后一个测试在遗漏体积修正时会失败。

短测试只证明实现的这些性质，不能证明 27 颗粒体系已经平衡，也不能决定最佳磁 sweep 数量。下一步正式实验应先检查初态依赖，再比较 ESS/秒和目标 MCSE。达到给定 cycle 数量本身不是停止依据。

当前模型仍没有显式有限容器。上述诊断不替代后续的 vdW、磁相互作用、构型熵与体系边界验证。MC cycle 始终不是物理时间。

## 8. R-hat = 1.83 是否意味着 body tilt 没有稳定态

不能由这个数作出该结论。需要区分：

- 固定角度不再变化。有限温度 MC 通常不会满足，也不需要满足。
- 稳定的角度概率分布。角度可以持续波动，但不同时间窗口及不同初态给出相同分布。
- 稳定的非零倾角。即使存在平衡分布，也未必有清晰的非零峰值。平均角大于 0 本身不是非零稳定倾角的证据。
- 全部位置与姿态自由度的热力学平衡。这还要求明确可归一化的目标分布。

旧实验保留了 12 × 1500 = 18000 个样本。body tilt 的 rank R-hat 为 1.8298，bulk ESS 为 17.446，均值 MCSE 为 1.5013°。R-hat 检测到链间或前后段不一致，不是百分比，也不能据此估算还需要几倍运行时间。非平稳状态下的 ESS 主要是警示，不能严格解释成已经拿到 17 个独立平衡样本。MCSE 不覆盖未收敛偏差。

也不能用 `18000 / 17.446` 断言每隔约 1032 cycles 就有一个独立样本，因为链间初态差异也影响这个多链 ESS。只有进入稳定混合区间后，才适合用 ESS 随计算量增长、MCSE 按平方根下降的近似规划后续预算。

即使最有利取向沿磁场，有限温度角度波动仍会给出正的平均夹角。平均 tilt 为几度，不能单独证明存在非零自由能最小值。

将旧实验保留段分成 cycles 501–1250 与 1251–2000，同一初态的四条链取平均：

| 初态 | 前段 body tilt | 后段 body tilt | 前段 Rg / nm | 后段 Rg / nm |
|---|---:|---:|---:|---:|
| compact_aligned | 4.5016° | 5.2365° | 29.8980 | 29.9995 |
| compact_tilted | 5.6495° | 4.9155° | 29.8742 | 29.9641 |
| expanded_tilted | 17.1323° | 9.1049° | 32.1011 | 32.1530 |

膨胀初态的角度仍在明显松弛，其尺寸也未回到紧凑初态的范围。现有证据直接支持有限运行尚未忘记初态，不足以证明不存在角度平衡分布。

## 9. 当前位置空间的边界问题

这是对代码中 Hamiltonian 的判断，不是由 R-hat 推断出的结论。固定中心只消除了整体平移，其他颗粒的位置仍无界。让一个非中心颗粒远离其余颗粒，排斥项消失，vdW 超过固定截断后为零，偶极项按距离三次方衰减。该颗粒的 Zeeman 和各向异性能量保持有限。

因此远处的 `exp(-U/kBT)` 趋于一个非零有限值，而位置积分包含 `integral r^2 dr`，在无穷空间发散。现有完整位置空间上的玻尔兹曼权重不能归一化。短时间内仍可表现为长寿命团簇，但不能把这种行为称为已经验证的无约束组装平衡。

固定几何后，磁矩的状态空间是 27 个单位球面的乘积，能量有限，条件磁分布可以归一化。因此磁更新数量可以先在这一明确的条件问题上标定。得到的最优数只针对所测固定几何，不自动推广到位置和姿态同时运动的体系。

构型熵也与采样测度和可访问状态数有关。显式采样位置与取向时，这些自由度的状态计数已经进入统计平均，不能再不加区分地重复加入同一部分的熵。若消去配体等未显式自由度，其有效自由能需要另行推导。整体缩放的 Jacobian 只是保证原有测度正确。

后续若研究完整热力学平衡，需要由物理问题确定有限容器、密度、约束或其他合理边界。这些选择会改变目标模型，本次不擅自加入。对稳定非零倾角的判断也应在明确目标后比较角度分布及自由能，并考虑角度测度，而不能只找一条曲线的平台。

## 10. 可恢复的优化实验

`scripts/run_sampling_optimization.py` 提供两种模式：

- `conditional`：冻结位置和本体，分别在四种几何下测试 1、5、10 magnetic sweeps。每种几何使用四条链，初始磁矩分别为随机、顺场、逆场和 body easy-axis。只在相同几何内部计算诊断，不合并不同条件分布。额外检查 27 个颗粒各自的场方向投影和 local beta。
- `joint`：启用原有机械自由度，对四种几何和多个 seed 做较长采样。输出全部变量的 pooled 和 per-start 诊断以及前后时间窗口均值。结果用于检查有限运行的混合，不宣称已经建立无约束平衡。

磁标定仅在所有被监测变量通过诊断后，按最差变量 bulk ESS/秒选择候选。时间包括 warm-up，多个进程的采样时间相加，wall time 另存。另要求平均 local beta 的 MCSE ≤ 0.25°、signed magnetization 的 MCSE ≤ 0.002。联合运行还保留原有 body/SL MCSE 要求。

试跑使用 seeds 11–14，独立磁验证使用 21–24，独立联合验证使用 31–34，与旧实验分开。初始化和采样流也按阶段区分。所有参数在开始后固定，不在生产样本中适应性调参。每条链完成后保存轨迹、最终 RNG 状态、数值校验和成功标记，支持同配置同源码下的 `--resume`。

独立联合验证使用四种初态、每种四条链、每链 4000 cycles，并舍弃前 1000。60 个 pooled 与组内诊断行均至少有一项未通过。pooled body tilt 的 rank R-hat 为 1.1915，bulk ESS 为 59.2，MCSE 为 0.663°。四种初态的后半保留窗口都比前半窗口具有更大的平均 Rg，同时 body order 下降。这说明联合结构仍在演化，不能用固定几何下磁变量的通过替代整体收敛。

## 11. 从发现问题到解决问题

1. 先确定目标。写清自由度、边界、能量和采样测度。目标不存在时，调 sampler 不能建立目标。
2. 排除实现错误。检查局部 delta 与完整能量之差、单位、磁矩归一化、姿态正交性、开关和 seed 复现。当前几何间隙检查只是现有投影近似，不等同于完整凸体碰撞测试。
3. 分离子问题。冻结几何测试磁采样，再测试联合采样。前者通过、后者失败，说明至少不能把全部问题归咎于磁更新次数。
4. 查看分布随窗口与初态的变化。除了均值，还要比较分位数、rank 分布、尺度、Rg 与能量。不能只挑看起来变平的一条链。
5. 找效率瓶颈。比较观测量的 ESS/计算时间，并检查不同 move 的接受率与实际位移。高接受率可能意味着步子过小，不表示高效率。
6. 在单独 pilot 中选择 sweep 数或 proposal，随后固定参数，用独立随机流验证。调参样本和验证样本分开保存。
7. 区分数值正确、采样混合与物理模型可信。三者分别需要证据。诊断未通过时记录失败，不修改门槛、删除拒绝样本或通过 thinning 美化结果。

从量化面试的角度，这对应“估计对象和偏差定义 → 基准验证 → 方差及自相关 → 单位计算成本的信息量 → 独立复验”。优化目标是规定精度下的计算成本，不是每秒生成最多相关样本，也不是把某个诊断数字调到好看。

# Reference: V9.03 energy code

`v903_cells/cell1.py` and `cell2.py` are copied unchanged from V9.03
(`_v903cells/` at tag `v9.03` of this repository).  `tests/test_model.py`
executes them to check, term by term, that V9.04 reproduces the V9.03
Zeeman, anisotropy, dipolar and steric energies and the V9.03 starting
structures.  They are not used by the V9.04 simulation itself.
